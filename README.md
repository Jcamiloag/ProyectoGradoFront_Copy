## Procesos realizados
Se implemento la navegación utilizando go_router tomando como ejemplo lo realizado en clase permitiendo así pasar un parámetro desde una pantalla principal hacia una pantalla secundaria en la cuál se ve el campo de texto y las opciones para llevar el mensaje a la pantalla secundaria.
## Modificaciones
Se adapto el proyecto base a el proyecto a desarrollar "Academia Farfala", se modifico los mensajes de texto en el home, los colores de la TabBar y el menú.
Se añadio una TabBar que consta de 2 columnas (Tabs), una de bienvenida donde se añadio un widget "Imagen" de los estudiantes de la academia y otra donde se añadio el GriedView dentro del TabBar permitiendo que en el primer tab quede implementada la GriedView con 7 items, los cuales se modificaron con algunos de los servicios (clases) con los que consta la academia, tanto la TabBar como el GriedView se añadio en la clase Home ya que se tomaría como información principal.
Se modifico los colores y tamaños de los parametros.
Se comento el contador para que no se muestre en la página principal para poder organizarla mucho mejor-
Se modifico el baseview para darle un color predeterminado a la TapBar
Se modifico el color de la pantalla secundaria de detalles.
